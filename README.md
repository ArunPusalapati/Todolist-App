# React Todo List App

A simple React application built with [Parcel](https://parceljs.org/) bundler and [React Router](https://reactrouter.com/) for navigation.  
This project demonstrates basic React concepts, routing, and component structure.

## 🚀 Features
- ⚡ Fast development with Parcel bundler
- 🛣️ Client-side routing using React Router v6
- 🎨 Simple and responsive UI
- 📦 Easy to run and build

- **JavaScript (ES6+)**

## 📦 Installation

1. Clone this repository:
   ```
      git clone https://github.com/your-username/react-todo-list.git
2. Navigate into the project directory:
   ```
      cd TODOLIST
3. Install dependencies:
   ```
      npm install
4. Running the Project
Start the development server:
   ```
      npm start
Parcel will start the dev server and open the app in your default browser.
